# 🏙️ Прогнозирование стоимости квартир в Самаре (Avito Flat Prices)

Проект по построению модели машинного обучения для оценки рыночной стоимости квартир в городе Самара на основе объявлений с сайта Avito. Пайплайн включает автоматический сбор данных, полноценный EDA, продуманный feature engineering и сравнение нескольких моделей регрессии.

## 📌 О проекте

**Цель:** разработать алгоритм, который на основе параметров квартиры (площадь, этаж, район, состояние ремонта, удалённость от центра и др.) прогнозирует её рыночную цену.

**Что решает проект:**
- Даёт объективную оценку стоимости квартиры на основе реальных рыночных данных;
- Позволяет выявить, какие характеристики жилья сильнее всего влияют на цену;
- Может использоваться как основа для сервиса автоматической оценки недвижимости или для проверки адекватности цены в объявлении.

## 🔄 Пайплайн проекта

```
Сбор данных (Selenium)  →  Очистка и EDA  →  Feature Engineering  →  Обучение моделей  →  Сравнение метрик
```

1. **Сбор данных** — парсинг объявлений о продаже квартир в Самаре с Avito.
2. **EDA** — анализ пропусков, распределений признаков, поиск и удаление выбросов.
3. **Feature Engineering** — заполнение пропусков, кодирование категориальных переменных, генерация новых признаков (расстояние до центра города, соотношения площадей и т.д.).
4. **Моделирование** — обучение и сравнение линейной регрессии и градиентного бустинга (XGBoost).
5. **Оценка качества** — сравнение моделей по RMSE, MAPE и R².

## 📊 Данные

Данные собраны самостоятельно с сайта [Avito](https://www.avito.ru) — раздел объявлений о продаже квартир в Самаре. Сбор реализован с помощью Selenium (`final_parser_code.py`) с обходом базовой защиты от ботов (`selenium-stealth`, headless-режим).

| Файл | Описание |
|---|---|
| `Samara_flat_data12.csv` | Структурированные параметры объявлений: цена, площадь, этаж, район, тип дома, ремонт, наличие лифта/парковки/балкона, координаты и др. (~5.6 тыс. объявлений) |
| `Samara_flat_description2.csv` | Текстовые описания объявлений (потенциал для NLP-фич) |
| `center_coords.json` | Координаты центра Самары для расчёта удалённости квартиры от центра |
| `metro_coords.json` | Координаты станций метро Самары |

По каждому объявлению собирается более 30 параметров: цена, район, улица, тип сделки, количество комнат, площади (общая/жилая/кухня), этаж и этажность дома, высота потолков, тип санузла, состояние окон и ремонта, наличие техники, тип дома и год постройки, наличие лифтов, характеристики двора и парковки, тип продавца и др.

## 🧹 Анализ данных и обработка признаков

В ноутбуках (`avito_linear_regression.ipynb`, `avito_xgboost.ipynb`) реализован полный цикл подготовки данных:

- **Анализ пропусков и выбросов** — гистограммы и boxplot для ключевых числовых признаков (площадь, высота потолков), удаление аномальных наблюдений и обрезка выбросов таргета по межквартильному размаху.
- **Восстановление пропущенных значений** — площадь кухни и жилая площадь достраиваются регрессией на основе общей площади, высота потолков — по среднему в группе по типу дома.
- **Кодирование категориальных признаков** — One-Hot Encoding для мультизначных полей (окна, парковка, двор, мебель, дополнительное оборудование) и для низкокардинальных категорий; порядковое/бинарное кодирование для признаков вида "количество комнат", "тип продавца", "наличие лифта".
- **Геопризнаки** — расчёт расстояния от квартиры до центра города по координатам с помощью `geopy.distance.geodesic`.
- **Новые признаки** — средняя площадь комнаты, плотность площади на комнату, доля жилой/кухонной площади в общей, отношение этажа к этажности дома.
- **Анализ корреляций** — построение корреляционной матрицы и изучение связи признаков с ценой квартиры.

## 🤖 Модели

Обучены и сопоставлены две модели:

| Модель | Ноутбук | Особенности |
|---|---|---|
| Линейная регрессия (Ridge/Lasso) | `avito_linear_regression.ipynb` | Пайплайн на `sklearn`, кросс-валидация, `GridSearchCV` для подбора коэффициента регуляризации, отбор признаков через `SequentialFeatureSelector` |
| XGBoost | `avito_xgboost.ipynb` | Оптимизация гиперпараметров с помощью `Optuna`, анализ важности признаков |

### Итоговые метрики на тестовой выборке

| Модель | RMSE, ₽ | MAPE | R² |
|---|---|---|---|
| Линейная регрессия (Ridge, кросс-валидация) | 1 143 500 | 15.4% | 0.82 |
| **XGBoost (оптимизирован через Optuna)** | **940 073** | **~10.9%** | **~0.88** |

Модель на основе градиентного бустинга показала более высокую точность предсказаний по сравнению с линейной регрессией: ошибка по RMSE снизилась примерно на **18%**, а средняя ошибка в процентах от цены (MAPE) — почти в **1.5 раза**. Это ожидаемо для табличных данных с нелинейными зависимостями и большим числом категориальных признаков.

> R² ≈ 0.88 означает, что модель объясняет около 88% вариации цен квартир на основе имеющихся признаков.

## 🛠️ Стек технологий

- **Python 3**
- **Сбор данных:** Selenium, Selenium Stealth
- **Обработка данных:** Pandas, NumPy
- **Визуализация:** Matplotlib, Seaborn, Plotly
- **Геоданные:** Geopy
- **Машинное обучение:** scikit-learn (Linear/Ridge/Lasso Regression, OneHotEncoder, TargetEncoder, Pipeline), XGBoost
- **Оптимизация гиперпараметров:** Optuna

## 🚀 Запуск проекта

1. Клонировать репозиторий и установить зависимости:

```bash
git clone https://github.com/nastyona1998/avito_flat_prices.git
cd avito_flat_prices
pip install -r requirements.txt
```

2. **(Опционально) Сбор новых данных.** Требуется установленный браузер Chrome и совместимый ChromeDriver:

```bash
python final_parser_code.py
```

3. **Обучение и сравнение моделей** — открыть и выполнить ноутбуки:

```bash
jupyter notebook avito_linear_regression.ipynb
jupyter notebook avito_xgboost.ipynb
```
